# 定时任务提醒插件 for AstrBot

一个智能的定时任务提醒插件，能够在对话中自动识别时间相关内容并设置提醒，无需特定指令。

## 功能特性

- ✅ 智能时间识别（支持多种时间格式）
- ✅ 自动设置提醒
- ✅ 定时发送提醒消息
- ✅ 持久化存储提醒任务
- ✅ 支持多种提醒格式
- ✅ 中文友好的时间表达式

## 支持的时间格式

- [x] 今天 12:30 开会
- [x] 明天 9:00 上班
- [x] 后天 18:30 健身
- [x] 周一 14:00 会议
- [x] 5月1日 10:00 劳动节
- [x] 3天后 12:00 项目截止
- [x] 提醒我 5分钟后 吃药
- [x] 提醒我 2小时后 休息
- [x] 提醒我 1天后 交报告

## 安装方法

### 方法一：通过插件管理器安装

1. 打开AstrBot管理面板
2. 进入"插件管理"页面
3. 点击"本地安装"或"添加插件"
4. 选择本插件的文件夹

### 方法二：手动安装

1. 将`reminder_plugin`文件夹复制到AstrBot的插件目录
2. 重启AstrBot

## 配置项

插件会自动使用默认配置，如需修改，请在插件配置文件中调整以下参数：

| 配置项 | 默认值 | 说明 |
|-------|-------|------|
| `enabled` | `true` | 是否启用插件 |
| `timezone` | `Asia/Shanghai` | 时区设置 |
| `reminder_file` | `reminders.json` | 提醒任务存储文件 |
| `check_interval` | `60` | 检查提醒的时间间隔（秒） |

## 依赖项

- Python 3.8+
- pytz库（时区支持）

```bash
pip install pytz
```

## 使用方法

### 基本使用

在对话中直接输入包含时间和任务的消息，插件会自动识别并设置提醒。

**示例：**

```
用户: 今天 12:30 记得吃午饭
AstrBot: 已设置提醒: 记得吃午饭
时间: 2026年02月17日 12:30

... 到时间后 ...
AstrBot: ⏰ 提醒: 记得吃午饭
```

### 支持的时间表达式

1. **今天/明天/后天** + 时间 + 任务
   - 例如：`明天 9:00 上班`

2. **周X** + 时间 + 任务
   - 例如：`周三 14:00 开会`

3. **X月X日** + 时间 + 任务
   - 例如：`12月31日 23:59 跨年`

4. **X天后** + 时间 + 任务
   - 例如：`5天后 10:00 交报告`

5. **提醒我** + X分钟/小时/天后 + 任务
   - 例如：`提醒我 30分钟后 吃药`

## 注意事项

1. 确保输入的时间格式正确，插件会自动识别
2. 提醒任务会被持久化存储，重启AstrBot后仍然有效
3. 到时间后，插件会自动发送提醒消息
4. 支持的时间精度为分钟

## 故障排除

### 提醒未生效
- 检查插件是否已启用
- 验证时间格式是否正确
- 查看AstrBot日志以获取更多信息

### 时间识别错误
- 确保时间格式符合支持的格式
- 检查时区设置是否正确
